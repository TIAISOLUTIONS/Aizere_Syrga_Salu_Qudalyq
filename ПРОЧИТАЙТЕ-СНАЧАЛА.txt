АЙЗЕРЕ — ГОТОВЫЙ САЙТ-ПРИГЛАШЕНИЕ

1. Откройте index.html, чтобы увидеть дизайн.
2. Откройте README.md — это полная инструкция на русском языке.
3. Создайте проект на supabase.com.
4. В Supabase → SQL Editor выполните весь файл supabase/schema.sql.
5. В config.js вставьте Project URL и PUBLIC Publishable key (или legacy anon).
   СЕКРЕТНЫЕ КЛЮЧИ, SERVICE_ROLE И ПАРОЛИ ПУБЛИКОВАТЬ НЕЛЬЗЯ.
6. Загрузите содержимое папки на GitHub так, чтобы index.html был в корне.
7. Settings → Pages → Deploy from a branch → main → /(root) → Save.
   Либо импортируйте этот GitHub-репозиторий в Vercel: Other, без сборки, output «.».
8. Откройте опубликованную ссылку на телефоне и отправьте пробный ответ.
9. Посмотрите запись в Supabase → Table Editor → guest_responses.
10. Удалите тестовые записи и отправляйте ссылку гостям.

Сайт НЕ опубликован в вашем аккаунте автоматически.
Облачная база и реальные ответы появятся после выполнения шагов выше.
До подключения базы кнопка отправки намеренно отключена.

Все тексты гостей — на казахском. Дата — 22.11.2026, 12:00 UTC+5.
В README.md есть оба варианта публикации, просмотр/экспорт ответов,
проверка безопасности, диагностика ошибок и описание файлов.

ПРОВЕРКИ В ПРОЦЕССЕ РАЗРАБОТКИ
Chromium: экраны 320, 360, 375, 390, 430, 768, 1024, 1440 px.
Нет горизонтального переполнения; ветки один / пара / отказ;
обязательные поля, исправление ошибок, диалог приватности;
отказ сети не показывает успех, повтор использует тот же ID.
Логика отправки проверена с тестовыми HTTP-ответами, НЕ с вашей облачной БД.
SQL выполнен в локальной PostgreSQL-совместимой PGlite: проверки полей,
повтор запроса, запрет чтения/прямой записи от anon успешно проверены.
Реальный iframe 2GIS загружен и показал адрес Жаркент, проспект Жибек Жолы, 137а.
